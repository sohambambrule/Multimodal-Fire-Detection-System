# Multimodal Fire Detection System

An ESP32-based IoT fire detection system that uses multiple sensors to detect fire early and send real-time alerts through the Blynk mobile application.

## Features
- Multi-sensor fire detection (Temperature, Gas/Smoke, Flame)
- Real-time mobile notifications via Blynk
- Local buzzer and LED alerts
- Wi-Fi enabled using ESP32
- Low-cost and easy to deploy

## Hardware
- ESP32
- SHT31 Temperature & Humidity Sensor
- MQ-2 Gas/Smoke Sensor
- IR Flame Sensor
- Buzzer
- LED

## Software
- Arduino IDE
- Blynk IoT
